# STREAMLIT STARTER KIT - CS HAD

## Bộ file gồm
- app.py: Dashboard mẫu.
- data.xlsx: Dữ liệu Excel mẫu.
- requirements.txt: Danh sách thư viện để cài local và deploy online.
- INSTALL_LIBRARIES.bat: Cài toàn bộ thư viện tự động.
- RUN_DASHBOARD.bat: Chạy dashboard.
- CHECK_INSTALLATION.bat: Kiểm tra Python, pip và Streamlit.
- OFFICIAL_DOWNLOAD_LINKS.txt: Link tải phần mềm chính thức.
- HUONG_DAN_STREAMLIT_TU_SO_0.docx: Tài liệu hướng dẫn đầy đủ.

## Trình tự sử dụng
1. Cài Python và chọn Add Python to PATH.
2. Cài Visual Studio Code.
3. Giải nén bộ file.
4. Nhấp đúp INSTALL_LIBRARIES.bat.
5. Nhấp đúp RUN_DASHBOARD.bat.
6. Trình duyệt mở tại http://localhost:8501.

## Khi triển khai lên Streamlit Community Cloud
